Work · 17 projects

Things I built — across macOS, web, AI, and content infrastructure.

Below is the full catalog, grouped by what each cluster does. Some are shipped products with paying or active users; some are open source; a few are experiments that taught me something I now reuse everywhere.

Selected highlights: Steward, a local-first macOS automation platform; DigitalYou, a tenant-aware AI communication platform; NavRead, a Vision-OCR reading library; clearweight, an open-source decision-analysis tool; and the AI content engine behind a YouTube channel that reached 35M+ views in two months.

01 · Automation & Communication

Operator-style systems built around desktop action, communication memory, tenant-aware workflows, and multi-surface execution across macOS, web, and iOS.

Steward
Swift · SwiftUI · Python · Supabase

Local-first macOS desktop automation platform with 12,500+ lines of Swift across 8 modular internal libraries. Records user workflows, replays them across desktop apps, and resolves changed targets with accessibility fingerprints, visual template matching, OCR, and screenshot verification. Self-healing replay is the whole point — automation that survives UI changes.

usestewardai.com →
DigitalYou
Next.js · Firebase · TypeScript · OpenAI · pgvector

Full-stack AI communication platform for email, calls, SMS, and social. Built with white-label multi-tenant architecture, pgvector-backed RAG memory, context-aware response generation, OAuth integrations, Playwright E2E tests, and automated leak-detection CI across 18+ migrations.

Omnyx
Node.js · Swift · AI/ML · macOS

Local-first macOS AI operator that executes multi-step workflows across apps with accessibility-tree perception, OCR support, and precision mouse/keyboard control. Targets the same problem Steward does, from a different angle — agentic execution rather than recorded replay.

Omnyx iOS
Swift · SwiftUI · iOS · Xcode

Native iOS companion interface for AI-powered communication workflows. SwiftUI-first design with mobile-friendly approval flows, inbox triage, and assistant interaction patterns.

02 · Knowledge & Decision Tools

Tools that turn messy knowledge, tradeoffs, and operational data into searchable libraries, scored decisions, and usable workflows.

NavRead
Swift · SwiftUI · SQLite · Apple Vision

Native macOS reading library for organizing highlights, importing PDFs, extracting text with Apple Vision OCR, and searching a local-first SQLite knowledge base with AI-powered semantic retrieval. The whole goal: your library should answer questions, not just sit there.

clearweight
Next.js · React · TypeScript · Vercel · OSS

Open-source decision-analysis tool that turns natural-language prompts into weighted scoring matrices. Real-time sensitivity analysis, drag-to-reweight sliders, and dual local/cloud AI provider support. Makes tradeoffs explicit instead of hiding them inside someone's head.

CRM · Google Business Profile
Express · Prisma · PostgreSQL · React

Full-stack Google Business Profile management platform with AI-powered optimization. Review management, photo galleries, marketing recommendations, and multi-location analytics for businesses operating across sites.

Gradium
React · Firebase · Stripe · Vite

Academic AI agent platform for student workload automation. AI chat, payment processing, multi-tier pricing, and intelligent task orchestration that maps work to outcomes.
